无题

ytkz2026-06-162026-06-16

你刚拿到普中51开发板，下面我用最详细、零基础也能看懂的方式，手把手带你点亮第一个LED。

整个过程分为四大部分：准备工作 → 安装软件 → 写程序 → 烧录运行，请一步步跟着做。

第一步：认识你的开发板（硬件准备）

拿出开发板，先看几个关键位置：

  1. 单片机芯片：板子中间最大的黑色方块，上面印着 STC89C52RC 或 STC89C51，这就是大脑。
  2. LED模块：通常在板子边缘有一排8个LED灯，旁边标注 LED 或 P2，并且用排针和跳线帽连接。
    • 找到这排LED，确认旁边的排针上有一个跳线帽（黑色小方块）插着。如果没有，请用盒子里附带的跳线帽把 P2 那组排针的左边两针短接（一般标注 P2_0 到 P2_7 旁边有排针，用跳线帽连接 VCC 和 LED 端或类似标识，具体看板子丝印）。普中板子大多出厂已连好，你只需检查跳线帽是否在“LED”相关位置。
  3. USB线：一端连电脑，一端连开发板的USB口（方形或Micro USB），给板子供电和下载程序。
  4. 电源开关：拨到“ON”的位置，此时电源指示灯（红色）应该会亮，说明板子已通电。

第二步：安装两个必备软件

1. 安装Keil C51（编写代码的软件）

  • 下载地址去搜索引擎搜 “Keil C51 V9.60” 或官网下载。
  • 安装步骤：双击 c51v960a.exe，一路点 Next，注意安装路径不要有中文（默认C盘即可）。到最后一步会提示安装驱动，都勾选允许。
  • 破解（如果不注册代码容量限制2K，点亮LED完全够用，可以先用着，后面再破解）：
    • 以管理员身份打开Keil，菜单栏点击 File → License Management，复制CID。
    • 打开注册机软件（需自行搜索下载），粘贴CID，Target选C51，点击Generate，把生成的码粘贴回License Management，点Add LIC。

2. 安装USB转串口驱动（CH340驱动）

  • 普中开发板大多使用CH340芯片实现USB下载。
  • 先不要插开发板。下载 “CH340驱动” （搜CH341SER），解压后双击 SETUP.EXE 安装。
  • 安装完成后，用USB线连接开发板，电脑会“叮咚”一声。右键“此电脑” → 管理 → 设备管理器 → 端口(COM和LPT)，看到 USB-SERIAL CH340 (COMx) 说明安装成功，记住COM号（如COM3）。

第三步：编写点亮LED的程序

1. 新建工程

  • 打开Keil，菜单 Project → New uVision Project。
  • 选择一个你容易找到的文件夹（比如桌面新建一个 LED 文件夹），起名为 LED，保存。
  • 弹出选择芯片窗口：展开 Atmel，选 AT89C52（因为STC89C52和它兼容），点OK。之后弹出的“是否添加启动文件”选择否。

2. 新建源文件

  • 菜单 File → New，或快捷键 Ctrl+N。
  • 此时出现一个空白编辑区，将下面代码完整复制进去：
#include <reg52.h>   // 包含51单片机寄存器定义头文件

// 延时函数，大概延时x毫秒 (粗略计算，晶振11.0592MHz)
void delay(unsigned int xms) {
    unsigned int i, j;
    for(i = xms; i > 0; i--)
        for(j = 114; j > 0; j--);
}

void main() {
    while(1) {          // 无限循环，让程序反复执行
        P2 = 0xFE;      // 1111 1110，让P2.0引脚输出低电平，LED点亮
        delay(500);     // 延时500ms
        P2 = 0xFF;      // 1111 1111，所有引脚输出高电平，LED熄灭
        delay(500);
    }
}

3. 保存并添加文件到工程

  • 点击菜单 File → Save，文件名取 main.c，注意后缀是 .c，保存。
  • 在左侧工程窗口，右键 Source Group 1 → Add Existing Files to Group，选中刚才的 main.c，点 Add，然后 Close。看到 Source Group 1 下出现了 main.c，说明添加成功。

4. 编译生成HEX文件

  • 先设置输出HEX文件：点击菜单 Project → Options for Target 'Target 1' （或快捷键Alt+F7）。
  • 切换到 Output 选项卡，勾选 Create HEX File，点OK。
  • 点击工具栏的 Build 按钮（三个小方块组成的一个图标），或按 F7 键。
  • 下方Build Output窗口显示 0 Error(s), 0 Warning(s)，并且最后一行显示 creating hex file from "LED"... 即编译成功，生成了 LED.hex。

第四步：烧录程序到单片机

1. 打开STC-ISP下载软件

  • 普中开发板会附带光盘或资料里有 STC-ISP 软件，若没有可搜 “STC-ISP V6.91” 下载。
  • 打开软件，界面如下操作：
    • 单片机型号：点下拉菜单，选择 STC89C52RC/LE52RC。
    • 串口号：选择之前在设备管理器里看到的COM口（如COM3）。
    • 打开程序文件：点击按钮，找到刚才工程文件夹里的 LED.hex 文件并打开。

2. 关键一步：冷启动下载

  • 查看开发板，确保电源开关目前是关闭状态（OFF）。
  • 在STC-ISP软件里点击 下载/编程 按钮，软件会显示“正在检测目标单片机…”。
  • 此时立即打开开发板电源开关（拨到ON）。这一步就叫“冷启动”，芯片重新上电时才能进入下载模式。
  • 软件会开始擦写和下载，进度条跑完，提示“操作完成”并有绿色文字表示下载成功。

3. 观察结果

  • 下载成功后，你会看到开发板上LED模块的第一个LED灯（D1或对应P2.0）开始闪烁——亮大约0.5秒，灭0.5秒，循环往复。
  • 恭喜，你已经成功点亮并控制了LED！

常见问题排查

  • LED不亮也不闪：检查LED跳线帽是否在正确位置，应连接P2口到LED组。有的板子需要跳线帽短接 P2 排针上的 “P2.0” 和旁边的 “LED” 针。
  • 下载失败，一直检测：检查电源是否在点击下载后立即打开；串口号是否正确；驱动是否装好；如果使用台式机，建议插机箱后面USB口。
  • 编译有错误：检查代码是否完全复制，每句结束后有分号，括号匹配，中英文符号不能混用（尤其是分号和引号必须英文）。

现在你已经走完单片机开发的完整流程。接下来如果想点亮其他LED或改变闪烁频率，只需要修改P2 = 0xFE; 中的值（0xFE让第一个灯亮，0xFD让第二个亮，0xFC让第一第二个同时亮……），然后重新编译、下载即可。
