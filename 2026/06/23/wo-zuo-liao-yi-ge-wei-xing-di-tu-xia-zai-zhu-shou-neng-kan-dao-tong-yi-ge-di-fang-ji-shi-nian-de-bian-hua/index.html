我做了一个卫星地图下载助手，能看到同一个地方几十年的变化

ytkz2026-06-232026-06-23

你有没有好奇过，你家门前那条路十年前长什么样？你住的小区那块地，以前是不是一片农田？你常去的那座山，在卫星图上看又是什么样子？

我就好奇过，然后做了个工具。

下图是香港迪士尼公园。

事情是这么开始的

有次在 GitHub 上偶然看到个项目叫 GEHistoricalImagery，能从 Google Earth 和 Esri 下载历史卫星影像。但它是个 C# 写的命令行工具，每次用都得敲一堆参数。

下图是它的架构：

我就琢磨：这玩意儿要是能有个网页界面，拖一拖、点一点就能看到几十年前的卫星图，岂不是更爽？

说干就干。

它能干什么

这个工具叫 GE Satellite Assistant，主要就三件事：

看历史卫星图。 切换到 Esri Wayback 数据源，点一下查询，它会列出这片区域所有可用的历史卫星影像和对应日期。选一个日期，地图上就会叠加上那个时期的卫星图。看着同一块地方从荒地变高楼、从农田变商场，挺震撼的。

框选下载。 你要是对某块区域感兴趣，直接框出来，选个缩放级别，它会告诉你这块区域有多少瓦片、拼接后图像有多大、文件大概多大。确认后就下载。支持导出 PNG 和 GeoTIFF 两种格式，其中 GeoTIFF 带有地理坐标信息，能直接扔进 ArcGIS 或 QGIS 里使用。

叠加中文标注。 默认就开着高德的中文道路标注，卫星图上直接显示路名、地名，不用自己猜这是哪儿。

踩过的坑

说几个印象深刻的。

Esri Wayback 瓦片地址怎么找？ 起初我照着别人的思路用了一种错误的 URL 格式，瓦片死活加载不出来。后来翻了 Esri 的 WMTS capabilities XML，才搞懂瓦片 URL 的正确拼法——原来 {z} 对应的不是标准 Web Mercator 的缩放层级，而是 WMTS 的 TileMatrix。调了一下午才对齐。

框选矩形莫名消失。 一开始用 Leaflet 原生的 L.Rectangle 做框选，结果矩形在地图缩放时直接不见了。排查半天，发现是事件监听的清理逻辑误伤了矩形。后来换成纯 DOM 覆盖层来画矩形，缩放时用地理坐标重新计算像素位置，才算搞定。

Google 地球影像有水印。 这个到现在也没完全解决。Google Earth 的历史影像瓦片经过 XOR 加密，需要先拿到 dbRoot 里的密钥才能解密。我参考 GEHistoricalImagery 实现了解密的部分流程，但浏览器的 CORS 限制让完整流程变得很棘手。目前的方案是：看历史图主要用 Esri Wayback（无水印）。

技术栈

非常轻量：

  • Vue 3 + Vite，前端框架
  • Leaflet，地图渲染
  • Esri Wayback WMTS，历史卫星影像数据源
  • geotiff 库，导出带地理坐标的 GeoTIFF
  • fast-xml-parser，解析 WMTS capabilities XML
  • 部署在 GitHub Pages，零成本

项目整体代码量不大，核心逻辑集中在几个文件里。想魔改的话，很容易上手。

在线体验

👉 https://ytkz11.github.io/ge-assistant/

打开即用，不需要注册，不需要 API Key。

写在最后

这个工具最初就是满足我自己的好奇心——想看看某个地方以前的样子。做到后来发现还挺实用：做城市规划研究的同事拿它看土地变迁，搞环境监测的朋友用它对比植被变化，还有人用它回看自己老家二十年来的模样。

如果你也有这种好奇心，不妨试试。

代码开源在 GitHub：https://github.com/ytkz11/ge-assistant

欢迎 star，欢迎提 issue，也欢迎直接 fork 一个自己的版本。
