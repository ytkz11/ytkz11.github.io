安装mimo code过程

2026年11月25日

安装mimo code过程很简单。

第一步，安装node.js

打开这个links:https://nodejs.org/en/download/

等待下载完毕后，打开安装程序，完成安装。

如果你已经安装过nodejs,请跳过这个步骤。

第二步，安装wezterm

打开这个links:https://wezterm.org/

我的电脑是win系统，所以这里选择Windows。

等待下载完毕后，打开安装程序，完成安装。

第三步，使用npm安装mimo code

打开一个cmd命令行，输入以下语句：

npm install -g @mimo-ai/cli

第四步，打开wezterm，输入mimo。

至此完成了mimo code的安装！

更多的细节操作请移步到https://mimo.xiaomi.com/zh/mimocode/start
